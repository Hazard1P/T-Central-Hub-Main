# T-Central identity

`tcentral-mark.png` is the custom transparent orbital T mark created for this project. Keep the original file intact; the shared `BrandLogo` component uses Next Image to deliver appropriately sized versions. Pair it with the T-CENTRAL wordmark and keep clear space around the silhouette. The icon is decorative beside the wordmark; home links provide the accessible brand name.

The landing page uses near-black (`#070e13`), warm white (`#f3f5f3`) and mint (`#baf5df`). The Earth artwork uses the existing attributed Solar System texture rather than a new external image. Landing-page illustration is static, so exploration remains accessible without loading a WebGL scene before launch.
